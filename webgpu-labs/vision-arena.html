The correctness badge compares the naive and tiled outputs pixel-by-pixel every frame: both kernels implement the same convolution, so any difference beyond rounding is a bug. On a software adapter both tiers run CPU-class by definition; the deltas become meaningful on hardware adapters.

What the kernels demonstrate

  • Workgroup-shared convolution: the tiled kernel stages a 20×20 tile (16×16 output tile + 4px apron) through workgroup memory: 256 threads loading 400 texels cooperatively, then computing from shared data instead of global reads
  • Coalescing: the naive kernel reads the source row-by-row per pixel (strided); the tiled kernel loads contiguous rows once for the whole tile
  • Honest timing: wall-clock per frame on the adapter, with the software renderer labeled as such
  • The same ladder scales up: the gaussian kernel here is the 2D cousin of the tiled GEMM in Inference Forge: same workgroup tiling, same apron handling, same correctness ledger
