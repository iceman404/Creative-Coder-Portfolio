Inference Forge

A quantized transformer inference engine hand-written in WGSL compute shaders. No compiler stack and no generated kernels: every GEMM, norm, and attention pass is authored, measured, and verified against a reference implementation.

What it will demonstrate

  • Packed 4-bit weight GEMM with dequantize-on-load, benchmarked against fp16
  • RoPE and RMSNorm as fused WGSL passes
  • Causal attention with a persistent KV cache, visualized as it fills
  • Top-p sampling with a live token stream
  • A per-kernel latency dashboard driven by GPU timestamp queries

Roadmap

  • Milestone 1: fp16 forward pass of a GPT-2 class model, correctness ledger vs fp32
  • Milestone 2: causal attention with a persistent KV cache
  • Milestone 3: 4-bit quantized kernels and packed weight loading
  • Milestone 4: streaming UI with per-kernel instrumentation

The honest benchmark

  • Target: memory-bound decode within striking distance of llama.cpp, on every GPU vendor, from a single URL
  • Milestone 1 numbers will be published here, unedited

Model registry (planned)

  • GPT-2 124M (fp16): 0.25 GB, 4 shards · tier: milestone 1 model
  • Qwen3-0.6B (Q4): 0.4 GB, 6 shards · tier B
  • Qwen3-1.7B (Q4): 1.1 GB, 14 shards · tier B
  • Qwen3-4B (Q4): 2.5 GB, 32 shards · tier A
  • Qwen3-8B (Q4): 5.0 GB, 63 shards · tier S
  • Source: HuggingFace resolve endpoints (CORS enabled), streamed with progress, SHA-256 verified per shard, cached in the browser Cache API
  • Loader: resume via byte-offset tracking and Range requests; cached shards are reused when the registry hash matches; the device tier gates which models unlock

The full engineering blueprint is public: docs/webgpu-labs-blueprint.md
