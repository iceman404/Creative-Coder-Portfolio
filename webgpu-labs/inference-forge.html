Inference Forge

A quantized transformer inference engine hand-written in WGSL compute shaders. Milestone 1 puts the foundation kernel on the anvil: the GEMM ladder: a naive reference implementation and a workgroup-tiled kernel, verified against a CPU reference and timed on whatever adapter your browser provides.

Reading the numbers: throughput is 2·N³ flops divided by the measured per-run time. Max abs error is the element-wise difference against a float64 CPU reference (small sizes) or the naive GPU tier (large sizes): both tiers must agree before a timing is trusted. On a software adapter every number is CPU-class by definition; the same ladder on hardware adapters is the real measurement.

Quantized GEMM: M3 kernels, live

Tier Time / run Throughput Weight stream Max abs error Status
Press Run quantized ladder to dispatch the fp32 reference and both 4-bit kernels.

The quantization trade: weights are packed two 4-bit values per byte (symmetric, per-32-element scales), so a run streams 0.625 × N² bytes of weights instead of 4 × N² — 6.4× less memory traffic for the same arithmetic. Max abs error here is measured against the dequantized-weight reference: it is the honest price of quantization, and the status column checks it stays inside the per-block scale bound rather than pretending it is zero. The two 4-bit tiers must also agree with each other bit-for-bit before any timing is trusted. Decode is memory-bound: this 6.4× is why quantized engines beat fp16 at the same arithmetic.
