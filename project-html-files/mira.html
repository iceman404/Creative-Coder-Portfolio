Embedded C & 8052 Assembly-Based DTMF Appliance Automation

Project Overview

This project implements serial communication between a SIM800L module and an 8052 MCU using DTMF tones. The system enables remote appliance control by interpreting DTMF commands sent from a cell phone to control devices such as LED bulbs.

Key Components & Functionalities

  • DTMF Tone Input: Receives tones from a cell phone and extracts control commands.
  • 8052 Microcontroller: Processes DTMF tones and executes control logic.
  • Appliance Control: Interfaces with appliances (e.g., LED bulbs) to toggle their state.
  • IR Sensor Integration: Monitors environmental changes or appliance status.
  • SMS Notification: Alerts users via SMS when IR sensor triggers occur.

Expected Outcomes

  • Fully functional DTMF-controlled appliance automation system.
  • Effective demonstration of DTMF tone interpretation using the 8052 MCU.
  • Seamless integration of IR sensors and SMS notifications for real-time alerts.

Significance

This project highlights the practical application of Embedded C and 8052 Assembly in remote appliance control. It demonstrates remote automation, sensor integration, and real-time notifications—paving the way for advanced home automation and security solutions.
